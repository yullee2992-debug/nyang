# 우리 냥이마을

친구들과 함께 각자의 고양이를 키우는 게임입니다. 만든 사람: 율

- 웹으로 하기: https://yullee2992-debug.github.io/nyang/
- 바탕화면 프로그램(냥이마을.exe)은 켤 때마다 이 저장소의 최신 게임을 불러옵니다. 여기 파일을 고치면 모두에게 자동 반영됩니다.
- `version.json`의 version 값을 바꾸면 켜져 있는 프로그램도 30분 안에 새 버전으로 바뀝니다.
- `database.rules.json`은 Firebase Realtime Database 규칙입니다.
