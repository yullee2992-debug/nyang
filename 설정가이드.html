냥이마을 설정 가이드

처음 한 번만 하면 돼요. Firebase로 "함께 쓰는 저장소"를 만들고, GitHub에 게임을 올려 링크를 만드는 순서예요. 전부 무료이고, 개인 PC에서 하는 걸 추천해요.

1. Firebase 저장소 만들기 약 10분

  1. console.firebase.google.com에 구글 계정으로 들어가서 프로젝트 만들기를 누르세요. 이름은 uri-nyang처럼 아무거나 괜찮아요. Google 애널리틱스는 꺼도 돼요.
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기. 위치는 싱가포르(asia-southeast1)를 고르고, 테스트 모드로 시작을 선택한 뒤 사용 설정을 누르세요.
  3. 만들어진 데이터베이스 화면에서 규칙 탭을 누르고, 안에 있는 내용을 전부 지운 다음 받은 파일 중 database.rules.json의 내용을 그대로 붙여넣고 게시를 누르세요.
    테스트 모드 규칙은 30일 뒤 자동으로 막혀요. 이 단계를 꼭 해야 계속 쓸 수 있어요.
  4. 왼쪽 위 프로젝트 개요 옆 톱니바퀴 → 프로젝트 설정 → 아래쪽 "내 앱"에서 웹 아이콘(</>)을 누르세요. 앱 닉네임을 적고 등록하면(호스팅 체크는 안 해도 돼요) firebaseConfig 값이 나와요.
  5. 받은 파일 중 config.js를 메모장으로 열고, firebase: null 부분을 아래처럼 복사한 값으로 바꿔 저장하세요. 
    window.NYANG_CONFIG = {
  firebase: {
    apiKey: "AIza...",
    authDomain: "uri-nyang.firebaseapp.com",
    databaseURL: "https://uri-nyang-default-rtdb.asia-southeast1.firebasedatabase.app",
    projectId: "uri-nyang",
    storageBucket: "...",
    messagingSenderId: "...",
    appId: "..."
  }
};
    databaseURL 줄이 꼭 있어야 해요. 없으면 2번(데이터베이스 만들기)을 먼저 하고 설정 화면에서 값을 다시 복사하세요.

2. GitHub에 올려서 링크 만들기 약 5분

  1. github.com에 가입하거나 로그인하고, 오른쪽 위 + → New repository를 누르세요. 이름은 nyang, Public으로 두고 Create repository.
  2. 만들어진 화면의 uploading an existing file 링크를 누르고, 압축을 푼 파일을 전부 끌어다 놓으세요. icons 폴더도 폴더째로 넣어야 해요. 아래 Commit changes.
  3. 저장소의 Settings → Pages에서 Branch를 main, 폴더를 /(root)로 고르고 Save.
  4. 1~2분 뒤 https://내아이디.github.io/nyang/ 주소로 열려요. 설정 화면에 "온라인 모드"라고 나오면 성공이에요. 이 링크를 단톡방에 공유하세요.

3. 바탕화면에 설치하기 친구들도 똑같이

  1. PC (크롬·엣지): 링크를 열고 주소창 오른쪽의 설치 아이콘(모니터 모양)을 누르거나, 메뉴(⋮) → 앱 설치를 누르세요. 바탕화면과 시작 메뉴에 냥이마을 아이콘이 생기고 별도 창으로 열려요.
  2. 안드로이드: 크롬 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치.
  3. 아이폰: 사파리로 열고 공유 버튼 → 홈 화면에 추가.

알아두면 좋은 점

  • 링크를 아는 사람은 누구나 들어올 수 있어요. 친구들 단톡방에만 공유하세요.
  • 주인이름 + 비밀번호 4자리는 친구끼리 쓰기 위한 간단한 잠금이에요. 다른 곳에서 쓰는 비밀번호는 쓰지 마세요.
  • Firebase 무료 요금제로 친구 여러 명이 노는 데는 충분해요. 결제 정보를 넣지 않으면 요금이 나가지 않아요.
  • 게임을 고치고 싶으면 GitHub 저장소에서 파일을 다시 올리면 돼요. 저장소를 Claude에 연결해 주면 수정과 업로드를 대신 해드릴 수 있어요.
  • 설치한 앱은 열 때마다 최신 버전을 받아요. 바로 반영이 안 되면 앱을 한 번 껐다 켜세요.
